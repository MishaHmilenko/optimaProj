=== Characters catalog & text game (database: offline samples) ===
· Type 'help' to list commands, 'exit' to quit.
> Mode: main

General
  Command        │ Description
  ───────────────┼──────────────────────────────
  help [command] │ list commands or describe one
  back           │ leave the current mode
  exit           │ quit the program

Information (read-only)
  Command                                                │ Description
  ───────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────────────────────
  ls [char|item|ability] [--filter text]                 │ list characters (default), items or abilities in the catalog
  show <id|name>                                         │ general information about a character, item or ability (with artwork links)
  sheet <char_id> [--toc] [--format plain|markdown|html] │ character sheet built with the structured-text system
  stats                                                  │ damage / healing statistics per character

Actions (change the catalog)
  Command                                                        │ Description
  ───────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────
  create <char|item|ability>                                     │ create a new character / item / ability through a dialog
  add <char_id> <item_id|ability_id>                             │ equip an item on / teach an ability to a character
  act <attack|heal|ability> <actor> <target> [--id <ability_id>] │ free-form action between two catalog characters (sandbox)
  undo                                                           │ undo the last 'act' action (Command + Memento)
  rm <char_id>                                                   │ remove a character from the catalog (asks for confirmation)

Remote database
  Command                                          │ Description
  ─────────────────────────────────────────────────┼─────────────────────────────────────────────
  db <refresh|chars|weapons|show|create|equip> ... │ remote character database (genshin.jmp.blue)

Storage
  Command          │ Description
  ─────────────────┼────────────────────────────────────────────────
  save [path.json] │ save the catalog (default: saves/catalog.json)
  load [path.json] │ load a saved catalog (replaces the current one)

Text game
  Command                                │ Description
  ───────────────────────────────────────┼───────────────────────────────────────
  game <roster|start|resume|results> ... │ turn-based battle with your characters
